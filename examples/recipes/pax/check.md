# Check my changes

Keep pax buildable, tested, tidy and free of lint warnings.

## When this happens
- Someone proposes a change or updates the main branch.

## Make sure
- The application builds.
- The tests pass.
- The code is formatted.
- The linter passes.

## Keep
- The build output.
- The test results.
- A record of what was checked.

## Afterward
- Report the result on the change.
