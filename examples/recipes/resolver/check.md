# Check my changes

Make sure every proposed change to Resolver builds and passes its tests before it is merged.

## When this happens
- Someone proposes a change or updates the main branch.

## Make sure
- The application builds.
- The tests pass.
- There are no type errors.

## Keep
- The build output.
- The test results.
- A record of what was checked.

## Afterward
- Report the result on the change.

## About this project
- The build output is in `packages/core/dist`, `packages/server/dist` and `packages/client/dist`.
